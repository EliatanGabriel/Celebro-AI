# Trabalho-BD

#area/faculdade #faculdade/trabalhos #conceito

**Resumo:** Trabalho da disciplina de Banco de Dados: modelagem e implementação de um banco de dados relacional.

## Descrição

- Modelar um banco de dados para um domínio definido (ex.: sistema de vendas ou matrícula).
- Entregar o diagrama entidade-relacionamento (DER) e o esquema relacional.

## Requisitos

- Aplicar normalização adequada às tabelas.
- Escrever o script SQL de criação das tabelas e consultas básicas.
- Seguir o roteiro e critérios de avaliação informados pelo professor.

## Planejamento

- Levantar os requisitos e identificar entidades e relacionamentos.
- Desenhar o DER e validar com o professor.
- Implementar o SQL e testar as consultas.

## Entregas

- Diagrama entidade-relacionamento.
- Script SQL de criação e consultas.

## Status

- [ ] Script SQL implementado
- [ ] Entrega final

# Trabalho-PI

#area/faculdade #faculdade/trabalhos #conceito

**Resumo:** Projeto Integrador: desenvolvimento de uma solução em equipe integrando várias disciplinas do semestre.

## Descrição

- Projeto em equipe que integra conteúdos de disciplinas do semestre.
- Objetivo: desenvolver uma solução prática para um problema proposto.

## Requisitos

- Definir tema e escopo em conjunto com o professor.
- Dividir tarefas entre os integrantes da equipe.
- Apresentar a solução em uma etapa de demonstração final.

## Planejamento

- Realizar reuniões de equipe e definir responsáveis por área.
- Manter cronograma de etapas e marcos do projeto.
- Integrar as partes desenvolvidas por cada integrante.

## Entregas

- Documentação do projeto (problema, solução, arquitetura).
- Demonstração ou apresentação final.

## Status

- [ ] Tema e escopo definidos
- [ ] Divisão de tarefas
- [ ] Desenvolvimento das etapas
- [ ] Apresentação final

# Fundamentos de Engenharia de Software

#area/faculdade #faculdade/disciplinas #conceito

**Resumo:** Fundamentos da Engenharia de Software: definição, objetivos, princípios e a diferença entre engenharia de software e programação.

## 1. O que é Engenharia de Software

Engenharia de Software é a aplicação de princípios de engenharia ao desenvolvimento de software. Não é apenas escrever código: envolve planejamento, projeto, construção, testes, manutenção e gerenciamento de todo o ciclo de vida de um sistema.

A IEEE define como: *"aplicação de uma abordagem sistemática, disciplinada e quantificável para o desenvolvimento, operação e manutenção de software"*.

## 2. Objetivos

- Produzir software de **qualidade** (confiável, eficiente e que atenda às necessidades).
- Entregar **no prazo** e dentro do orçamento.
- Gerenciar a **complexidade** de sistemas modernos.
- Reduzir **custos de manutenção** ao longo do tempo.

## 3. Engenharia de Software × Programação

| Programação | Engenharia de Software |
| --- | --- |
| Foco em escrever código | Foco em todo o ciclo de vida |
| Tarefa individual | Trabalho em equipe |
| Curto prazo | Longo prazo e manutenção |
| Sem processo definido | Processos e padrões |

## 4. Princípios importantes

- **Abstração** — focar no essencial, escondendo detalhes.
- **Modularidade** — dividir o sistema em partes menores e independentes.
- **Coesão** — cada módulo deve ter uma responsabilidade única.
- **Acoplamento baixo** — módulos devem depender pouco uns dos outros.
- **Separação de preocupações** — separar interface, lógica e dados.

## 5. O processo de software

Um processo de software é um conjunto de atividades que leva à produção de um produto de software. As atividades genéricas são:

```
Comunicação
    ↓
Planejamento
    ↓
Modelagem
    ↓
Construção (código e testes)
    ↓
Entrega e implantação
    ↓
Manutenção
```

## 6. Qualidade de software

A qualidade envolve atributos como:

- **Funcionalidade** — faz o que deveria fazer.
- **Confiabilidade** — não falha em condições normais.
- **Usabilidade** — fácil de usar.
- **Eficiência** — uso adequado de recursos.
- **Manutenibilidade** — fácil de modificar.
- **Portabilidade** — roda em diferentes ambientes.

## 7. Papéis da equipe

Uma equipe de software pode incluir:

- **Analista de requisitos** — levanta e documenta necessidades.
- **Desenvolvedor** — implementa o código.
- **Testador/QA** — valida a qualidade.
- **Arquiteto** — define a estrutura técnica.
- **Gerente de projeto** — planeja e acompanha.
- **DevOps** — cuida de implantação e infraestrutura.

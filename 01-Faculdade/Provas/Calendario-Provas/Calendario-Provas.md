# Calendario-Provas

#area/faculdade #faculdade/provas #conceito

**Resumo:** Calendário com datas, disciplinas e status de preparação de todas as provas do semestre.

## Checklist de provas

- [ ] Prova de Algoritmos — conteúdo e data registrados
- [ ] Prova de POO — conteúdo e data registrados
- [ ] Prova de Banco de Dados — conteúdo e data registrados
- [ ] Prova de Engenharia de Software — conteúdo e data registrados
- [ ] Prova de TI — conteúdo e data registrados
- [ ] Prova 1 do semestre — data registrada
- [ ] Prova 2 do semestre — data registrada
- [ ] Prova final — data registrada
- [ ] Prova substitutiva — critérios verificados

## Datas

- Registrar aqui as datas de cada avaliação conforme divulgadas pelos professores.
- Marcar as provas como concluídas após cada avaliação.

## Conteúdos

- Apontar para a nota de cada prova para consultar o conteúdo cobrado.
- Conferir o plano de estudo em [[Revisao-Prova]].

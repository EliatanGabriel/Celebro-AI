# Projeto-IoT

#area/projetos #projetos/ativos #conceito

**Resumo:** Projeto ativo de desenvolvimento de uma solução IoT.

## Objetivo
Desenvolver uma solução IoT que coleta dados de sensores, transmite para a nuvem e permite visualização.

## Escopo
Hardware, sensores, firmware, conectividade, armazenamento e painel de visualização.

## Passos
Escolher o hardware, prototipar os sensores, configurar a nuvem, integrar o envio de dados e testar em campo.

## Roadmap
Protótipo, integração, testes, documentação e evolução.

## Tecnologias
ESP32/Arduino, sensores, MQTT/HTTP e plataforma de nuvem.

## Bloqueios
Custo de hardware, conectividade e tempo de prototipagem.

## Status
Em andamento; protótipo funcional.

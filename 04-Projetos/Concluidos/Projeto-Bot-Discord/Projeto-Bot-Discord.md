# Bot para Discord

#area/projetos #projetos/concluidos #conceito

**Resumo:** Bot de Discord para comunidade de estudos.

## Objetivo
Criar um bot para a comunidade de estudos no Discord que automatiza funções de apoio, moderação e informação.

## Escopo
- Comandos de estudo e lembretes
- Moderação básica (boas-vindas, regras, filtros)
- Integração com APIs quando necessário

## Passos
Levantar comandos com a comunidade, escolher a biblioteca, implementar o MVP, hospedar e testar em beta.

## Roadmap
Levantamento, MVP, beta, lançamento e ajustes contínuos.

## Tecnologias
Python (discord.py) ou Node (discord.js); banco de dados simples; hospedagem gratuita.

## Bloqueios
Limites da API do Discord, custo de hospedagem para escala e manutenção contínua.

## Status
Concluído; pequenos ajustes sob demanda.

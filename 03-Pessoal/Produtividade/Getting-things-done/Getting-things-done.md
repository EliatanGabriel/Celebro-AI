# Getting-things-done

#area/pessoal #pessoal/produtividade #conceito

**Resumo:** Método de produtividade baseado em capturar e processar tarefas.

## Conceitos-chave
- Princípio central: nada fica na cabeça; tudo é capturado em um sistema confiável.
- Fluxo de 5 etapas: capturar, esclarecer, organizar, refletir e engajar.
- Cada item vira uma "próxima ação" concreta, não um título vago.
- Revisão semanal mantém o sistema atualizado e a mente livre.

## Como aplicar
- Use uma caixa de entrada única para capturar qualquer compromisso ou ideia.
- Ao processar, aplique a regra dos 2 minutos: faça já se demorar menos que isso.
- Transforme cada item em uma próxima ação (verbo + objeto + contexto).
- Organize listas por contexto (@casa, @trabalho, @computador) e por projeto.
- Reserve um horário semanal para revisar, limpar e planejar.

## Boas práticas
- Capture instantaneamente; não confie na memória.
- Toda tarefa precisa de uma próxima ação definida.
- Mantenha poucas listas, simples e legíveis.
- Esvazie a caixa de entrada diariamente.

## Armadilhas comuns
- Transformar o sistema em uma lista morta que ninguém consulta.
- Criar listas gigantes sem contexto e sem próxima ação.
- Processar por reação emocional em vez de regra.
- Pular a revisão semanal até o sistema ficar obsoleto.
- Confundir GTD com uma simples lista de tarefas.

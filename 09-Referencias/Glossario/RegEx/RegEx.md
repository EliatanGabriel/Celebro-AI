# RegEx

#area/referencias #referencias/glossario

**Definição:** expressão regular — mini-linguagem para descrever padrões de texto. Caracteres literais casam consigo mesmos; metacaracteres (`.` `\d` `+` `*` `[]` `^` `$`) descrevem classes, repetições e âncoras. Serve para buscar, validar e extrair dados em qualquer editor, terminal ou linguagem.

**Exemplo:** `\d{5}-?\d{3}` casa CEP (`12345-678`). Pegadinha: `.` casa *qualquer* caractere — para um ponto literal use `\.`.

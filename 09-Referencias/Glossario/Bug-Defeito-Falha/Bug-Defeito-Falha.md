# Bug-Defeito-Falha

#area/referencias #referencias/glossario

**Definição:** na terminologia ISTQB, três coisas distintas: **erro** é a ação humana errada (o dev digita errado); **defeito** é a consequência no código (a lógica incorreta que mora no software); **falha** é quando esse defeito aparece em execução (sistema se comporta mal). Um defeito pode existir sem falhar nunca — por isso teste não prova ausência de bugs, só presença.

**Exemplo:** dev confunde `<` com `<=` (erro) → validação de idade aceita -1 (defeito) → tela de cadastro salva usuário com idade negativa (falha).

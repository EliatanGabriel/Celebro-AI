# JSON

#area/referencias #referencias/glossario

**Definição:** formato texto para trocar dados entre sistemas: pares `"chave": valor` dentro de `{}` (objeto) ou `[]` (array). Valores possíveis: string, número, booleano, null, objeto aninhado e array. Padrão de facto das APIs modernas — leve, legível por humanos e parseável por qualquer linguagem.

**Exemplo:** `{"nome": "Eliatan", "idade": 25, "skills": ["QA", "SQL"], "ativo": true}`. Pegadinhas: aspas duplas obrigatórias, sem vírgula final, sem comentários.

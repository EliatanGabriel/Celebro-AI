# Anotacao-Erro

#area/trabalho #trabalho/anotacoes #conceito

**Resumo:** Registro de erros encontrados e como foram resolvidos.

## Como usar
- Criar uma nota por erro ou por sessão de investigação, com descrição clara do sintoma.
- Registrar o erro o mais cedo possível, mesmo sem solução, para não perder contexto.
- Atualizar a nota quando a causa e a solução forem descobertas.
- Revisar a coleção de erros periodicamente para identificar padrões recorrentes.

## Estrutura
- **Sintoma:** o que aconteceu, mensagem de erro exata, tela e passo a passo para reproduzir.
- **Causa raiz:** hipótese e confirmação da causa (config, dados, código, ambiente).
- **Solução:** o que resolveu, com comandos ou trechos de código relevantes.
- **Ambiente:** versões, navegador, SO, branch e configuração usada.
- **Aprendizado:** como evitar esse erro no futuro e se ele afeta outros cenários.

## Dicas
- Copie a mensagem de erro completa: erros diferentes parecem iguais se forem resumidos.
- Registre também as tentativas que não funcionaram, economizando tempo em investigações futuras.
- Ligue o erro ao bug formal no tracker quando houver, anexando o link.
- Use a busca no vault para achar erros similares antes de investigar do zero.

# Anotacao-Daily

#area/trabalho #trabalho/anotacoes #conceito

**Resumo:** Anotações rápidas da reunião diária.

## Como usar
- Criar uma nota por dia ou manter uma nota por semana com seções por data.
- Registrar antes da daily o que você fez e o que vai fazer, para falar em poucos segundos.
- Anotar bloqueios e dependências que o time precisa destravar.
- Usar a nota como rascunho do que precisa virar tarefa ou bug formal.

## Estrutura
- **Data:** identificação do dia/semana.
- **Ontem:** o que foi feito, com resultado relevante.
- **Hoje:** o que será feito, priorizando o que destrava o time.
- **Bloqueios:** impedimentos, pendências de outros e o que é preciso decidir.
- **Ações:** encaminhamentos combinados com os participantes.

## Dicas
- Seja breve: daily é para alinhar, não para relatar tudo.
- Transforme bloqueio em pergunta objetiva (ex.: "quem pode validar o ambiente de staging?").
- Acumule pendências não resolvidas e leve para o planning ou para o 1:1.
- Atualize a nota no fim do dia para registrar o que de fato foi concluído.

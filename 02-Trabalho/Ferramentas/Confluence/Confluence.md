# Confluence

#area/trabalho #trabalho/ferramentas #conceito

**Resumo:** Wiki corporativa para documentação colaborativa da equipe.

## Conceitos-chave
- Wiki corporativa para documentação colaborativa.
- Espaços agrupam páginas por área ou projeto.
- Macros: tabelas, code blocks, inclusão de issues do Jira.
- Versionamento e comentários em páginas.
- Permissões por espaço e página.

## Exemplos
```
# Estrutura típica de espaço de QA
Documentação de QA
  ├─ Padrões de Teste
  ├─ Planos de Teste
  ├─ Relatórios de Release
  └─ Runbooks e Procedimentos
```

## Boas práticas
- Manter páginas atualizadas junto com o código.
- Usar templates para padronizar documentos.
- Linkar páginas entre si e com issues do Jira.
- Definir dono e revisão periódica das páginas.
- Publicar relatórios de release e planos de teste.

## Armadilhas comuns
- Documentação desatualizada em relação ao produto.
- Páginas órfãs sem link nem dono.
- Duplicação de conteúdo entre espaços.
- Permissões erradas (acesso excessivo ou restrito demais).
- Usar a wiki como repositório de código ou dados sensíveis.
